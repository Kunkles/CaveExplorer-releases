# Cave Explorer

**A first-person sci-fi thriller in the dark.** You're a survey contractor
for a mining corporation, sent into caves on alien worlds with no weapons:
just a power pack you crank by hand, a helmet, and a few battered survey
drones that scan the rock into a map on your visor. The last crew came
through before you. It did not go well.

## Playing it

Start with **TUTORIAL**: a SysCorp orientation walks you through the drones,
the map, cranking, and holding your breath. **CONTROLS** on the start menu
(or Esc in game) lists every key.

The game checks this page when it starts and says so on the start menu
when a newer build is out.

- **Windows:** run `CaveExplorer-Windows.exe`. SmartScreen may warn about
  an unknown publisher: *More info*, then *Run anyway*.
- **macOS:** unzip and open *Cave Explorer*. The app isn't notarized, so
  the first time, right-click it and choose *Open*, then *Open* again.
